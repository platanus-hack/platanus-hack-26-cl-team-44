# Toki OS · MVP heredado

El código fuente está en [prototipo/woki-os.html](../../prototipo/woki-os.html), heredado de `woki-ux-prototipo`. Esta carpeta es el índice de la futura aplicación, no una copia divergente. Conservamos el nombre del archivo y las rutas para facilitar el trabajo con Emmy.

Desde la raíz: `python3 -m http.server 8000 --bind 127.0.0.1 --directory prototipo`. Abrir http://localhost:8000/woki-os.html y elegir «Usar mouse (demo)». Cámara y APIs externas requieren su configuración; el modo mouse permite revisar la interfaz.
