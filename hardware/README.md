# Hardware

## Kit para un canal cableado

| Pieza | Cantidad en la prueba | Función |
|---|---:|---|
| MyoWare Muscle Sensor | 1 | Adquisición de actividad muscular superficial |
| MyoWare Link Shield DEV-18425 | 1 | Alimentación y salida por TRS; seleccionar ENV |
| Electrodos adhesivos | 3 | Contactos MID, END y REF |
| TRS macho–macho CAB-18983 | 1 | Señal, alimentación y tierra entre shields |
| Arduino Shield DEV-18426 | 1 | Conector A0 y alimentación desde UNO |
| UNO compatible ATmega328P | 1 | Digitalización de A0 y envío USB |
| USB de datos y adaptador si hace falta | 1 | UNO a portátil |

Inventario reportado: 3 sensores, 3 Wireless Shields, 2 Link Shields, 2 Cable Shields, 2 TRS, 1 Arduino Shield, electrodos y cables de referencia. Las cantidades no sustituyen inspección física.

**Cable Shield ≠ Link Shield.** El primero conecta electrodos remotos mediante un cable de tres electrodos; no se conecta al A0 del Arduino Shield. En el montaje directo no se usa ni hace falta CAB-12970. El Wireless Shield tampoco se apila en la prueba alimentada por UNO.
